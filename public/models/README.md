# Folder Model 3D

Letakkan model produk untuk viewer interaktif dengan nama **`product.glb`**.

Export dari Blender: _File → Export → glTF 2.0_ → Format **glTF Binary (.glb)**,
centang _Apply Modifiers_, dan usahakan ukuran file di bawah 5 MB
(kecilkan tekstur ke 1024–2048 px).

Jika file belum ada, viewer otomatis menampilkan logo 3D Jastif.id.
